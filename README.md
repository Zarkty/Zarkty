## 👨‍💻 Sobre mí

**Ingeniero Informático** (Grado en Ingeniería Informática, Universidad Isabel I) y **Systems & Cloud Infrastructure Engineer** especializado en el ecosistema Microsoft: **Modern Workplace**, gestión de endpoints, **identidad y accesos (IAM)** y seguridad **Zero Trust**.

- 🖥️ **+1.500 endpoints** gestionados con despliegue **Zero-Touch** mediante Microsoft Intune y Windows Autopilot.
- 🔐 Diseño de políticas de **Acceso Condicional**, MFA y gobierno de identidades en **Microsoft Entra ID**.
- 🛡️ **Hardening** de equipos Windows con Microsoft Defender for Endpoint, reglas ASR, BitLocker y Windows LAPS.
- 🔄 Migraciones de **Active Directory on-premise a identidad híbrida** y de file shares a SharePoint Online / OneDrive.
- ⚡ Automatización de operaciones con **PowerShell** y **Microsoft Graph API**.
- 👥 Experiencia liderando un equipo técnico de 4 personas (soporte L1/L2 y análisis de datos y seguridad).
- 🌍 Español nativo · Rumano bilingüe (C1) · Inglés (B1).
